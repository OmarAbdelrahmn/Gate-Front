# تحديث قاعدة هنقر المستضافة — 4 نوفمبر 2026

## النطاق

Backend فقط، دون تعديل أو نشر Frontend. تحديث قاعدة ERP المستضافة القائمة، ثم ربط بيانات الحسابات وأصحابها والمستخدمين الواردين في ملف التأسيس. لا إنشاء لموظفين مجهولين ولا تصفير لمحافظ هنقر.

## ما تم على القاعدة

- نجحت تجربة ترحيلي Application وIdentity داخل معاملة متراجَع عنها.
- نجح BACKUP DATABASE مع COPY_ONLY وCHECKSUM وفق رد SQL Server. تعذر RESTORE VERIFYONLY بسبب غياب CREATE DATABASE في master، وتعذرت قراءة msdb.backupset؛ لا يدعي هذا التقرير التحقق من استعادة النسخة.
- ثُبّت `20261104115133_AddHungerOperationsQualityAndSharedAccountContext` و`20261104115200_GrantHungerAndPlatformFieldPermissions` وتحقق وجودهما باتصال جديد.
- أضيفت 10 جداول ضمن hunger، وحقول وسجلات سياق مشتركة، و20 تعريف صلاحية. بقيت قيود جاهز القديمة دون منصة محددة؛ القيود المشتركة الجديدة معزولة بمعرف المنصة والمشرف.
- أداة التنفيذ: `tools/Apply-HungerMigration.ps1`؛ تعيد التجربة مع rollback قبل التطبيق، وترفض النشر الجزئي أو هدف قاعدة مختلف.

## بيانات التأسيس

المعاينة المعتمدة وجدت 311 حسابًا مطابقًا و311 صاحب حساب مطابقًا، دون صفوف حسابات مرفوضة، و171 مستخدمًا فعليًا مطابقًا. المستخدم طلب تعليق الهويتين غير الموجودتين بدل إنشاء أشخاص جدد.

اكتمل اعتماد بيانات التأسيس. إيصال الاستيراد الدائم: `01a1a670-8147-77cd-b318-336ea837ba9d`. تحقق اتصال مستقل من وجود 311 سجل مصدر، و311 رابط صاحب حساب، و171 مستخدم مصدر مطابق، ومن ResultJson المحفوظ بالقاعدة.

يبقى **173 طلب تكليف من المصدر للمراجعة**، يتضمن المستخدمين الاثنين غير المسجلين وصف المحفظة غير الصالح. لم تفتح عملية استيراد بيانات الحسابات تكليفات نشطة أو قيود محفظة آليًا. إنشاء التكليف يمر بمراجعة المحفظة والتأكيد وسياسات التكليف القائمة؛ السالب والموجب والصفر جميعها مقبولة.

## التحقق المحلي

- بناء API ناجح دون تحذيرات أو أخطاء.
- أُعيد البناء بنجاح بعد تحسين تحميل بيانات الاستيراد على دفعات؛ أداة الاستيراد بنيت بنجاح أيضًا، ونجح git diff --check. قفل DLL مؤقت من Defender زال بإعادة البناء، ولم يتطلب تعديل الحماية.
- 42 اختبارًا مركّزًا ناجحًا، تشمل الجودة، المحفظة ذات الإشارتين وتقسيم اليوم؛ يشمل الاختبار المخصص SQL Server محليًا معزولًا.
- لا اختلاف موديل مع ترحيلات Application أو Identity.
- حزمة Domain.UnitTests: 282 ناجحًا و3 إخفاقات في مكونات لم تعدل: FuelCard DTO يتوقع Guid بدل Guid?، وقائمة الاستثناءات لا تضم ImportFuelCards، وتقييد دور على CorrectCompletedOilChangeVehicle. لا ينسب التقرير نجاحًا كاملًا للحزمة العامة.
- توجد وثائق مستقلة [للمسارات](hunger-api-endpoints.md)، و[الصلاحيات](hunger-new-permissions.md)، و[الاستيراد](hunger-import-rules.md).

نشر ملفات API على الاستضافة ليس مثبتًا بهذا التقرير؛ وجود الترحيلات لا يعني أن الخدمة الحية تشغل النسخة الجديدة.

# تحديث واجهة خزينة جاهز والتحقق من الربط

التاريخ: 19 أكتوبر 2026، بتوقيت الرياض.

## ما تغير للمستخدم

- واجهة موحدة لجميع صفحات الخزينة، بتبويبات واضحة ومساحات أوسع وخط أوضح وألوان المشروع الحالية.
- الأسماء الرئيسية: «الأرصدة والحركات»، «تحويل وقبض وصرف»، «تسليم النقدية»، «بترو آب»، «التقارير»، «حسابات الخزينة»، «إعداد الخزينة».
- ملخص مستقل لتصفيات المشرف، ورسوم المشرف، والخزينة الرئيسية، والبنك.
- إجمالي النقدية والبنك يستبعد تحصيلات بترو آب؛ تحصيلات بترو آب لا تمثل رصيد محفظة الوقود.
- الأرصدة المعروضة مسجلة في النظام، ولا تعني أن جميع المبالغ متاحة للصرف؛ قد توجد مبالغ بانتظار التسليم.
- عرض نص توضيحي لملكية أموال كل شركة واستقلالها عن الشركات الأخرى.
- بحث واضح في حركات الصفحة الحالية، مع إعادة الصفحة إلى البداية عند تغيير الفلاتر.
- خطوات مبسطة لتسليم النقدية دون تغيير شروط مطابقة كل حساب أو صلاحيات التأكيد.
- نوافذ حوار تدعم لوحة المفاتيح: حصر التركيز، إغلاق Escape، وإعادة التركيز إلى زر الفتح.
- الجداول والتبويبات تمرر أفقياً داخل مساحتها في الشاشات الضيقة.
- أسماء الأشخاص تظل الأسماء المعروضة؛ لا يستخدم عنوان محضر التسليم معرفه الداخلي كبديل لرقم المستند.

## إصلاحات الربط التي كشفها التحقق

1. حقول تقرير الحسابات أصبحت مطابقة لاستجابة .NET: `opening` و`payments` و`closing`؛ كانت الواجهة تستخدم أسماء أخرى قد تظهر صفراً أو شرطة بدلاً من القيمة الصحيحة.
2. أضيف عرض بيانات `fuel` عند اختيار تقرير بترو آب. تظهر القيم غير المثبتة «غير متحقق»، مع فصل التحصيل والشحن والتخصيص وكشوف الرصيد والاستهلاك.
3. تنزيل التقارير يحتفظ بامتداد PDF أو XLSX حتى إذا لم يتمكن المتصفح من قراءة اسم الملف من ترويسة الخادم.
4. فشل تحميل حسابات الخزينة يوقف عرض الملخص كأنه ناجح، حتى لا تخلط الواجهة رسوم المشرف مع التصفيات.
5. فشل تحميل التقرير أو سجل الحركات يظهر برسالة وإعادة محاولة، بدلاً من إظهاره كأنه نتيجة فارغة سليمة.
6. الطلب الأقدم لتقرير لا يستبدل نتيجة طلب أحدث عند التبديل السريع.
7. الحسابات الرئيسية في التقرير تحمل «إجمالي مجموعة» مع تنبيه بعدم جمعها مرة أخرى مع الحسابات التابعة.

## التحقق المنفذ

| الفحص | النتيجة |
| --- | --- |
| بناء Next.js للإنتاج `npm run build:next` | ناجح؛ جرى توليد 118 صفحة |
| TypeScript | ناجح ضمن البناء، وكذلك فحص مستقل أثناء التنفيذ |
| فحوص عقد API والعميل | 13 ناجحة |
| اختبارات خدمات جاهز في الخلفية | 205 ناجحة، 16 متجاوزة |
| lint للمكونات الجديدة وسكربت التحقق | بلا أخطاء أو تحذيرات |
| lint لصفحات الخزينة القائمة | توجد مخالفات سابقة؛ المقارنة مع النسخة الأصلية لم تجد زيادة بسبب إعادة التصميم |
| الحوارات بلوحة المفاتيح | تم التحقق من Tab وEscape واستعادة التركيز |
| المقاسات | هاتف، مقاس متوسط، وسطح مكتب؛ لا تمدد أفقي للصفحة، والجداول الطويلة تمرر داخلياً |

فحوص العقد تقارن أسماء حقول TypeScript مباشرة بتعريفات C# للحسابات والتقارير والمطابقة والفلاتر والتسليم والتحويل والشحن. وفحوص العميل تؤكد إرسال الفلاتر، وامتداد التنزيل، وعدّ النقدية بما فيه الصفر، ونسخة السجل، ومفتاح إعادة المحاولة. لا تنفذ هذه الفحوص معاملات حقيقية.

## التحقق على الخدمة المتصلة

جرى التحقق من العرض بحساب مسجل دخوله في التطبيق المحلي:

- تحميل الحسابات والأرصدة وسجل الحركات وقوائم الشركات.
- تحميل التسليمات وفتح نافذة معاينة طلب تسليم دون إرساله.
- تحميل أدلة بترو آب ومطابقتها وظهور القيم الناقصة كغير متحققة.
- عرض تقارير الحركات وأرصدة الحسابات وشركة التجارية وبترو آب.
- تقرير التسليم يعرض طلب اختيار محضر معتمد؛ لا يوجد محضر معتمد في البيانات الحالية بعد إعادة البداية المالية.
- طلبا PDF وExcel وصلا إلى رسالة نجاح التصدير في الواجهة. لم يتوفر ملف تنزيل محفوظ عبر أداة المتصفح لفحص محتواه في هذه الجولة؛ اختبارات الخلفية تتضمن توليد PDF وExcel من بيانات التقرير نفسها.
- فحص 13 مسار قراءة وتقارير دون تسجيل الدخول أعاد 401 كما هو مطلوب.
- لم تظهر أخطاء تطبيق في سجل console أثناء الفحص؛ ظهرت تحذيرات من إضافة متصفح خارجية.

## حدود التحقق وحالة التشغيل

- اختبارات SQL Server والتزامن والمعاملات التي تحتاج بيئة اختبار منفصلة ظلت متجاوزة؛ فحوص InMemory لا تثبت هذه الضمانات.
- لا توجد مطالبة بأن مؤشرات الأداء الميدانية أو تدقيق قارئ الشاشة أو العرض الداكن اجتازت قياساً لم ينفذ.
- لم تنفذ تحويلات أو صرف أو تأكيد تسليم أو تفعيل على البيانات المستضافة ضمن هذا التحديث.
- الخدمة المتصلة تظهر الخزينة غير مفعلة و17 حساباً يحتاج إثبات الرصيد. الصفر في السجل بعد البداية الجديدة لا يثبت أن النقدية والبنك والمحفظة الفعلية تساوي صفراً.
- لا يتضمن هذا العمل نشر الواجهة أو نشر نسخة جديدة من الخلفية.
